# R1-11 / 12 关注、反馈和独立内容 API

本批实现 `/api/interests`、`/api/feedback`、`/api/reader-preferences`、`/api/feed`、`/api/contents/{id}` 及显式导读请求。身份复用 Access，本机预览仅允许回环地址；写入要求同源。GET 使用只读一致快照，不写偏好、不排导读、不付费。新偏好独立于旧事件筛选，不推断或填充用户关注。

单用户版本 CAS、稳定 mutation ID 与审计回执阻止旧设备覆盖和撤销后的重复请求复活。内容后续成为 canonical 别名时，已有反馈按最新明确操作归入规范内容，更新/撤销一并处理旧身份记录，不删除审计历史。两条真实 PostgreSQL 连接证明 CAS 冲突；两个同时首次导读请求返回同一持久任务。

流只读取获准来源、当前材料一致且特征/准入/卡片三类审核均通过的 R1 内容，不要求 Event，不回退旧摘要。推荐把实际阅读价值、当前价值、明确关注、反馈及软多样性分开解释；关注总加分不超过 2，单次负反馈不扩展成领域排除。最新只采用有依据的原始/编辑版/问题创建时间，日期不补午夜，抓取/转载/修改/导读不刷新首发顺序。`config/r1-reader.yml` 及实现前记录说明 AI 暂定参数，不当作用户阈值。

分页固定时点、版本与偏好，纠正材料、来源发布范围或偏好变化返回 409；非法/到期游标 400。规范别名不占重复位置，并保留实际观察到的来源渠道。详情用纯文本段落，范围、作者角色和时间含义独立呈现；问题没有回答、媒体只有简介时不生成观看结论。GET 不触发导读；POST 同一版本只排一个任务，终止失败不假装已重新排队。

验证：另行新建并迁移至 `000015` 的 `unspun_r1_reader_tests_20261017` 上 **814 项通过、无跳过**；Ruff、Pyright 与 Alembic schema 检查通过。独立审查发现的 canonical 反馈滞留、首次导读并发唯一键冲突、详情反馈状态遗漏均修复并专项验证。原 `000014` 仅增加偏好/反馈/审计表，不改写历史文章、事件或日报。

真实 API 预览为本机 `http://127.0.0.1:8112`，连接独立 `unspun_r1_api_20261016`，并非开发默认库。实际 GET 返回空偏好和 `no_reviewed_published_contents`，没有用 R0 C 编号、手工卡片或离线正文冒充已发布内容。页面与真实操作证据在 13/14 批记录。

**边界**：00B 技术基准已冻结，但最终卡片质量评测被未知费用预留阻塞；正式来源发布、新付费消费者和真实三类内容闭环仍待 G1/G2/16。本批不启用任何生产付费或来源发布，12 的最终整体验收不以空列表替代。来源/作者关注只匹配现有材料，未连接的采集能力明确告知。
