## 查询与行为

[契约](../superpowers/specs/2026-10-20-r2-03-candidate-detail.md)及 D-032 固定详情按规范 ID 校验当前材料、card/features/admission、同处理指纹、模型/契约与布尔审核通过，再验证中文、证据和材料。来源关闭、材料范围不符、未审核、失效、原文/元数据修订均不回退到旧结果。别名解析、64 跳和环路检查保持。合格新闻/分析退出原推荐时效窗口后仍按原日期阅读；旧知识/评论无统一年龄淘汰，不能借历史背景恢复被拒或失效结果。

候选 SQL 先筛当前版本、来源/材料和原时效，再按来源与动态/知识评论/未知日期分组稳定轮转，最多原 1,000 个；各组按原发时间、ID 倒序，不截最早 ID，不提高上限。名额外可直接阅读；推荐不保证遍历全历史。原权重、兴趣/反馈、软多样性与最新排序未改。正文和卡片在有界 ID 后加载、渠道批量读；核心候选仅两条 SQL，详情版本查询只限该 ID。迁移 `000017` 只新增部分当前卡片及规范身份表达式索引。

API 字段、游标格式、排序版本和 TTL 保持；快照增加检索版本、材料/元数据及三类审核更新，来源发布范围也参与。晚于 as_of 的新增不挤入旧页，材料/准入、来源范围或偏好修订返回 409；格式/过期仍为 400。GET 不生成或付费，显式导读请求继续原时效、去重和预算约束。
