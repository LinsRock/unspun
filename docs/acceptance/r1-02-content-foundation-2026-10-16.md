# R1-02 内容底座与处理归属

日期：2026-10-16。基线 `8aedaf9`（R1-01 / PR #65），任务为 [R1-02](../tasks/r1.md)。本任务只交付增量 schema、版本契约和旧消费者隔离，不启用采集、付费处理或新版发布。

## 已交付的边界

- `articles.id` 继续是正式内容 ID，URL 原唯一约束保留；新增处理归属、形式、平台/发布方、语义元数据指纹、规范对象与当前材料指针。历史行默认 `legacy/unknown`，作者、元数据与材料继续未知，没有批量补造。
- 新增平台身份、URL 别名、逐路径观测、不可变材料与版本化派生表。平台 ID 带命名空间，别名唯一；同内容跨来源观测可并存，缺排名/互动保持空。材料与当前指针、派生结果有复合外键，不能串用别的内容的材料。
- 作者含身份平台、角色与依据；原发、feed、修改、转载、编辑版及问题创建时间分别记录。日期精度不接受虚构零点，未知时间不得带断言时间；媒体 URL 只接受 HTTP(S)。安全段落是纯文本结构，不提供原站 HTML 注入接口。
- 派生复用指纹覆盖语义元数据、材料、范围、抽取器、生成/审核契约及模型。新结果不覆盖旧正文、摘要或旧审核字段；`ready` 必须有对象形状的输出与审核凭证，JSON null 不算证据。真正生成/审核与材料失效规则由 08–10 接入，当前没有伪造 ready 结果。
- 旧摘要、复用、embedding、聚类、失败计数、publication/backlog 查询排除 R1；直接调用也拒绝 R1。事件级评分、观点与新日报选编排除混合归属，避免间接消费 R1 成员；旧日报读取不改写。

规范关系的非自指与身份唯一性由 DB 约束；URL 主记录与别名的统一解析、规范对象传递关系和更新失效由 05/08 的事务入口承接，不把模型表本身申报为去重器或抓取器。
