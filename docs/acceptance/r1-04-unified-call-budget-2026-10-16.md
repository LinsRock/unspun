## 实现与覆盖范围

- 客户端共同入口在 HTTP 前，以预算行锁串行校验已知费用、未决预留、月份 carry、阶段及 grounding 限额；先独立提交一条物理请求，再发送网络请求。旧用途、embedding 和截断内部重试没有绕过路径。
- 每次物理响应费用独立提交到唯一已发生费用账本 `llm_usage`。解析失败、业务事务回滚、后续审核失败和进程退出不回滚已记费用；同一个请求重复结算不重复计费。旧摘要和新任务入口把预算失败记为延期，不消耗内容失败次数；审核预算耗尽时保留已付费草稿。
- 缺费用、无效费用、连接中断或进程强退保留 `usage_unknown/reserved` 和占用；不填零，不因超时或跨月自动释放。缺 token 但费用已确认时 token 保持 null。历史无关联继续 `not_recorded`，不补造 task/content 关系。
- R1 生产 card/guide 必须携带真实持久内容任务及有效尝试/租期；记录 task、attempt、content、source、stage、phase。领取过期不能开启付费。相同逻辑请求已响应时可复用，未知请求阻止盲目再付费；同规范对象有未知请求时阻止新阶段重复请求。
- 有 generation ID 的未知费用可通过认证只读 `/generation` 的匹配 ID、`total_cost` 核对，保留原响应和核对证据，恰好一次进入账本；无 ID 或费用未知就继续占用。不能承诺所有超时都能自动核对。供应商[用量说明](https://openrouter.ai/docs/cookbook/administration/usage-accounting)为核对字段依据。
- 超出预留的真实费用先保留，预算再暂停并记 incident；不能为了满足预留丢弃供应商费用。此保护不是对供应商绝不会违规收费的承诺。新请求按保守预留控制，未知请求仍需核对。
- embedding 在共同入口前分成不超过 32768 UTF-8 字节的批次，每批独立预留/记账；超出单条上界明确失败，不偷偷截断材料。聊天上界为 262144 输入字节，模型不在登记价格表时拒绝请求。
- 现有成本查询总额、充值与固定费用语义保留，调用列表增加真实关联，新增物理请求只读查询；总预算展示执行状态/未知占用。每百候选分母为 distinct R1 candidates、每入选分母为 distinct ready admissions、每导读分母为 distinct ready guides；月投影按实际合格日增量。当前阶段未运行，均 `unmeasured`，不以测试 fixture 或历史事件代替新流量。15/16/17 接真实统计与页面。

## 操作与回退

在 `server/`，始终显式指定新建已迁移的隔离 URL。只读状态：`uv run python -m unspun.core.billing_admin status`。隔离评测仅使用一个已登记的库执行一次 `initialize-evaluation`，随后复用它的已知费用与预留，不能每次新建空库重获额度。生产 `initialize-production` 仅在 16 已满足任务/G1/来源开关时执行；它读取当前环境 key，不输出 secret，不更改供应商设置。`reconcile --request-id <id>` 只接受已有 generation ID 的权威费用响应。

回退关闭 R1 消费者并保留预算/请求/费用；旧 worker 继续零副本。不得删除未决预留、清空账本、降级删除表或以重跑旧循环诊断。旧镜像可读原费用列，但其客户端没有共同预算保护，因此不能用旧镜像恢复任何付费消费者；安全回退镜像必须包含 `000013` 及预算客户端，或保持全部付费关闭。该 PR 完成账务底座，不表示 G1/G2 或最终 R1 用户验收已通过。
