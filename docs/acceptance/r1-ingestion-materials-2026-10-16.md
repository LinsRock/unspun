已实现：RSS/Atom 元数据先落候选、身份/URL/来源观测，再原子投递材料任务；作者角色、feed/修改/原发/转载时间及精度分开，未知热度仍为 null。跨来源同 URL/平台 ID 保留观测；重复投递不重复写相同版本。材料任务独立请求，记录访问、响应/文本指纹、安全段落、源摘要及实际范围；短讯、预览、问题背景和媒体简介不被扩为文章全文。无真实媒体内容时没有字幕、时长或时间点声明。

`000014` 将旧全局 URL 唯一约束改为 `(url, processing_track)` 唯一，保留原 legacy 行及其事件/日报关系；同 URL 的 R1 身份单独保存。无删表/删列、无历史正文/摘要/费用改写。旧发现只领取 legacy owner，新的阶段配置全部默认关闭，后台区分配置、owner、阶段声明和实际运行状态。

材料抓取验证每次重定向的公开地址及来源域边界，有输入/结构上界；继承隐藏祖先、排除脚本/隐藏内容和隐藏广告媒体。已核实的新华社正文容器/刊载日期/记者署名优先，通用抽取不能用模板补已知容器缺失。通用抽取的完整度保持 unknown；日期不带时区时不造精确时刻。压缩响应不会二次解码。

确定性正文身份保留拉丁词边界，规范 Unicode/中文换行；仅按实际核实的尾部 CCTV 署名及版权边界分离 credits，原证据留在材料版本。没有相似度百分比合并。短事务最终写入以一个有界 identity lock 保护 canonical 图，网络在事务外并行；原发、材料或元数据变化使旧派生失效。旧任务必须匹配最新原发现/本渠道语义版本，不能用晚到结果退回旧标题。根对象变更后，为未变化的重复项选同一个新根；重定向按最终 canonical 比较，不窃取别人的 URL。访问暂时降级时保留最后观测材料及原取得时间，失败版本另存，不伪装本次又取得全文。
