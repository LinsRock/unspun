# R1 用户终验反馈与阅读页收尾 · 2026-10-18

用户对正式 R1 的实际验收结论为 **“有小问题但可接受”**，并提出以下六项阅读页反馈。本批据此收尾；不将该总体验收转填为原 43 条逐条评分，也不推断使用设备或外站播放结果。R2/R3 未启动。

## 六项反馈与处理

| 项 | 实际原因或要求 | 本批结果 |
| --- | --- | --- |
| 1 | 同一卡片多个“文中称”，疑似重复或不同来源的总结 | 卡片属于一个内容对象，其多个不同要点被后端逐条加上归属前缀。正式 API 的 25 条内容、53 个要点中，13 条具有重复的“文中称”前缀。前端将完全一致的归属集中为一次“AI 要点 · 原文陈述”等标注；各条文字、顺序、限定词和证据不改。观点/评价/分析/解释、问题背景与简介分别标注；混合或不一致归属保留原样，不强行变成客观事实。详情的卡片要点采用相同显示。 |
| 2 | 感兴趣/不感兴趣使用向上/向下拇指图标 | 空心/实心图标区分未选/已选，保留再次点击撤销、无障碍名称、键盘焦点和悬停说明，点击区域 44×44px；提交中显示局部进度。 |
| 3 | 不显示阅读价值技术判断和单条反馈范围的说明 | 已移除指定说明；推荐解释与原始来源入口仍可展开。 |
| 4 | 推荐/最新切换不要反复显示“已保存，可随时撤销。” | 排序仍正常跨设备保存，但成功静默；重复点击当前排序不写入。保存冲突和网络异常仍显示，未绕过版本检查或自动重试写入。 |
| 5 | 页面和消息加载状态更专业 | 路由、列表、详情与关注初读使用骨架屏；刷新、分页、反馈提交和导读处理使用局部进度。偏好变化重排时保留同排序的现有卡片，避免整页闪空；错误不伪装成空列表。遵循减少动态效果设置。 |
| 6 | 顶部不显示“中文阅读 · 原文可溯” | 已移除右侧文案。 |

没有修改模型、提示词、评分、来源开关、生产频率或费用账本。没有重新运行付费评测。正常生产调度的消费与本批只读 UI 验证分开计。
