# R1-03 持久任务与独立调度

日期：2026-10-16，基线 `a2d0371`（PR #66）。任务：[R1-03](../tasks/r1.md)。新增 `000012` 与任务仓储/有界线程执行器，不启动生产消费者，不运行旧日报或旧 AI 循环。

## 交付与约束

- 唯一投递键含队列、阶段、规范对象、输入、策略版本和周期；相同键的 payload 冲突会拒绝，不静默改写已投递输入。来源断开多周期后仅排当前周期。
- 真实 Postgres `FOR UPDATE SKIP LOCKED` 短事务领取，提交后才执行网络；同一对象的跨阶段运行受部分唯一索引约束，不在网络期间持有长事务。
- 单调领取版本、租期、执行者和独立尝试留档；完成时验证当前领取版本/租期。业务结果、后继任务和完成状态共用事务；过期或晚返回不写业务结果。外部请求不承诺严格恰好一次，付费未知状态由 04 继续保账。
- 尝试总数单调递增，故障次数另计；故障有退避与有限次数，预算延期必须给出未来时间且不消耗故障重试。材料受限是 blocked，不记“不值得看”。
- 每条来源保存 owner、启用、下一周期及运行/新增状态。扫描跳过已有未结束来源任务，不能绕过退避或堆积多个周期；领取再次核对来源 owner/启用。来源故障退避与任务重试统一，成功后恢复正常周期。
- discovery/material/deadline 各有独立执行槽与调度钩子；paid/guide 默认为零槽，不注册的 handler 不领取。默认两槽只是当前实现参数，不是用户确认的来源或产品周期。源码入口在 handler 未接入时明确退出 2，不冒充正常消费。
