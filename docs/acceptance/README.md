## 后续写入

- 普通 lint、测试、构建与 CI 检查：在 PR 中记录结果和运行链接，日志留在 CI 或临时目录，不提交日志、JUnit XML 或整份 CI 状态 JSON。
- 真实模型/预算、必要失败复现或用户验收：只保存结论无法替代的最小原件、来源/时间与关联信息。
- 不默认导出整库、整个工作目录、所有环境信息或复制已有基准；同一原件由多个结论链接复用。
- 新增文件时说明其使用者或未结问题。交付结束后，无当前依赖的过程产物按同样方式退出当前版本，保留可核对的 Git 恢复位置。
