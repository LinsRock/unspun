# R1-16 材料范围发布围栏与新窗口准备

来源级开关不能表示“只通过某种材料范围”。本次增加独立 `paid_scopes` / `publish_scopes`：材料仍完整留存，只有符合获准范围的材料才入付费任务；存量任务在调用前再次检查，范围暂停不发生模型调用、不消耗失败次数，配置恢复后可复用原任务。内容流、直接详情和导读请求同样检查范围，避免仅限制列表而绕过详情/导读。

18 路配置全部写明材料范围：已有有界技术复核的 10 路仅列其实际范围，未通过的 8 路为空。**discovery/material/paid/publish 开关均未改变，所有生产阶段仍关闭**；这不是新增来源发布、质量通过或预算初始化。未知来源或缺省配置的向后兼容不代替本轮逐路径发布审核。

后台来源 API 展示处理/发布范围，材料任务结果保留未入付费原因。原物理费用、未知预留、任务、材料及历史日报不改写；提示词、模型、评分、用户评分与评测分配不变。

## 新华社全身份只读复核

在目标 `00600c3` Linux 镜像与网络、256 MiB/0.5 CPU、最多两个来源请求并行的环境，对原窗口全部 **175 个不同身份**做一次材料复核（最初 30 个及后续新出现 145 个）。175 份请求均返回可解析材料；当前提取器记为 126 份开放文本、49 份视频材料，其中 7 份视频实际只有记者/编导/制作署名，没有简介。这个后续单次读原站结果不能冒充原窗口当时已经验证了全部材料。

时间核对没有发现 feed 上海日期与取得的原页日期冲突；作者缺失继续未知，视频 URL 均来自原页，不生成转录或观看结论。7 份署名材料保留为原始失败依据，修正为没有可读材料，避免再用标题替它补出简介。包含实际简介的媒体材料继续保留，源署名留在审计证据；材料版本为 `r1-material-v3`。

由于原窗口主声明为单一开放文本，混合范围测量与当前版本均需要新的前瞻窗口。已在启动前登记[新窗口契约](../evaluations/r1/material-window-v2.json)：新华社/BBC World 明确声明开放文本与媒体简介两种实际范围，保留原 6 小时、13 次、跨两个上海日期、90% 成功率及零关键错误门槛；没有降低数字、删掉无材料分母或改写旧失败。每轮两份材料轮换抽样，分别审核文章与媒体，署名页/验证壳/空材料仍算材料未取得。

拟在本批镜像部署后按 26 轮、30 分钟间隔运行独立只读观察，实际启动版本、起止时间、已完成数和失败另追加；本文不预记未来轮次，也不因配置或修复合并而认为 G2 通过。所有数据库配置和模型 key 均不传入观察容器。旧 AI worker 与新 R1 worker 都保持停用。
