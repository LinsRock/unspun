## 接入契约

旧 `/api/feed` 和 `/reading` 调用保持。后续页面显式请求 `/api/feed?mode=mixed&sort=recommended&limit=20`（或 latest）；当前 `UNSPUN_R2_HYBRID_ENABLED=false`，通过身份校验后为 404。启用仍需另行验收，API 无 mock 参数。

响应 `r2-hybrid-v1` 的条目含 `type`、字符串 `id`、依赖 `version`、`time`、`ranking`、`presentation`、`reference_to`，以及互斥的 `content`/`topic` 材料。content 内保留原整数 ID，原详情、兴趣、反馈/撤销继续沿用；没有话题关注/反馈。页长、排序、as_of 与当前依赖绑定游标；非法/过期或跨排序/页长为 400，候选/资格/偏好变化为 `409 hybrid_changed_restart`，调用方须重新加载第一页。

重要性、显式兴趣、真实公共关注分通道召回，再与可读保底融合。只读 `config/r2-hybrid.yml` 信号登记初始为空；没有采集/生成生产者，不把发现列表位置、来源数量、转载或阅读分当作公共关注。有效登记必须绑定对象版本、观测/到期时间、原始依据和审核者；重要性需公共影响及材料引文，公共关注只接直接互动或公开榜位。缺失信号为 null 并列在 `missing_signals`，不声称真实信号覆盖已完成。

每次至多装载 600 个内容、32 个话题候选；超出注册范围的遗漏为 `outside_boundary=not_evaluated`。当前内容资格及原时效复用，反馈别名以 SQL 批量解析，最新版本/原 ID 的胜出规则与原 Reader 一致。话题逐次调用未放宽的 R2-07 公开资格，检查物理凭证、审核及当前依赖；mock、失效成员、材料或关闭来源不能发布。话题单项 16 active 成员/32 当前进展键上限，历史修订在 SQL 中取当前版本；无话题时独立阅读正常。

内容按原发/原有有据编辑日期排序；话题取合格实质进展 occurred 优先、reported 后备。未知时间保留，日期不伪造时刻；转载、处理和导读更正不置顶。仅同页的明确重复/纯转载概况压成可打开的 reference，任何独特观点/解释/体验保护，跨话题独特关系也优先保留。所有 ID 仍在分页集合中，跨页或话题失效后恢复完整卡片。
