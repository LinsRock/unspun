# T9 PWA 与离线日报实施计划

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 手机桌面安装后，断网重开仍能读已在线加载的当天日报。

**Architecture:** Workbox 预缓存应用外壳，PersistQueryClientProvider 恢复 IndexedDB 中的日报快照；不另设 API HTTP 缓存。

**Tech Stack:** Vite PWA、Workbox、TanStack Query persist client、idb-keyval、Vitest、fake-indexeddb。

- [x] 新建 `web/src/queryPersistence.ts`：导出 `createQueryClient()`、`createDigestPersister()`、`digestPersistenceOptions`，使用 idb-keyval 的 get/set/del 实现 Persister，七天保存期与 `digest-v1` 版本。
