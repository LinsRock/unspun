# M2 T8 三页路由与日报页面

用户已授权实施 T8，视觉沿用已确认的 T-D1 原型，不另行重设计。

- `/` 保留事件流和观点展开；`/report` 独立呈现已有运行报告；`/digest` 默认请求北京时间当天日报，日期置于 `?date=YYYY-MM-DD`，支持前后一天、日期输入、返回今天及浏览器后退。未生成当天日报时明确提示，可通过“最新一期”读取最新已生成日报，不静默把历史日报当作今天。
- 桌面采用 216px 侧栏；手机采用顶部品牌与主题切换、底部三项导航。导航使用 React Router，直接刷新任意页面可用（既有 Caddy SPA 回退已覆盖）。
- 日报沿用导语卡与热度排名列表，显示生成时间、24h 窗口、摘要、快照分数和可追溯的观点摘录。原文只放行 http(s)，所有观点与 article_id 对应。
- 明确处理加载、404 未生成、空日报、网络失败、无效日期；失败提供重试。未来日期不可选择，日期计算统一北京时间，不依赖设备时区。
- Vitest 覆盖路由、日期请求与历史切换、排名与摘录链接、404/空状态/错误、安全外链。完成后启动本地 API 和 Vite，以桌面、400px 手机宽度及明暗主题验证。
- 本地数据库目前为空且没有 LLM 密钥；体验验收将使用独立的本地演示数据库，提供当前与历史日报，明确说明为演示数据，不改生产数据。
- 遵守 D-012：用户体验验收通过前不创建 PR，也不把 T8 标记为最终完成。用户已于 2026-10-10 实际体验并明确验收通过，现可按项目工作流提交 PR。
