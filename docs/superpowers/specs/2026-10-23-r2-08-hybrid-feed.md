# R2-08 首批混合后端冻结契约

基线 `origin/main ed21aaf`；独立 `r2-hybrid-feed` worktree/venv。本文件先提交再实现。用户授权本批后端、PR/CI/合并与关闭部署；不做页面、R2-09+、清理、付费或提供方查询。R2-06 暂缓、3/4、真实质量未通过；R2-07 真实质量未测，不补记通过。

## 响应和资格

沿用 `/api/feed`，增加 `mode=content|mixed`，缺省 content，旧响应/调用方保持。mixed 默认推荐，可切最新；`UNSPUN_R2_HYBRID_ENABLED=false` 时返回 404。版本 `r2-hybrid-v1`；每项明确 type=content|topic、字符串 ID、依赖版本、原始时间精度/依据、理由及版面呈现。内容反馈仍用原整数 ID；不增加话题关注/反馈。

内容复用当前资格与 R2-03 时效；话题逐次调用 R2-07 `qualified_topic_text`，保持来源/成员/材料/派生/审核/物理凭证的当前依赖校验和 mock 拒绝。无合格话题时独立内容正常可读。API 没有 mock 参数；模拟话题只交给离线纯排序函数，结果标明 fixture，不能进入生产或作为真实质量。

## 召回与信号

分别召回 important、interest、public_attention，加 readable 保底。内容每通道上限 120/120/120/240，先过滤当前版本及时效，按来源和 current/evergreen/unknown 分轮；合并后最多批量装载 600 条。话题每通道最多 8 条，取当前合成版本并按实质时间/领域分轮；最多 32 条调用原资格校验。单话题最多 16 active 成员、32 当前进展键；超界只跳过话题。历史修订由 SQL 选最新，不全量装载。边界外遗漏单列，不声称全库召回。

重要性/公共关注使用独立、有对象版本、观测/到期时间、原始依据及审核者的只读配置登记，随 PR 审查，本批不增加采集/模型生产者。公共关注只允许直接互动观测或公开榜位（URL、指标、原值）；重要性要求材料引文及明确公共影响判断。来源数/转载数/阅读价值不能冒充信号。初始登记为空，真实样本如实缺失；配置拒绝工程信号，工程夹具只进入离线函数。过期、无效或错版本信号不加分。

复用已有显式内容兴趣/反馈/撤销与 CAS；领域/词/来源/作者沿用原匹配。话题只匹配自身领域/标题词，不传播成员反馈，不创建订阅。不读取点击/滚动/时长/隐式已读。

## 排序、时间与抑重

工程暂定参数不是用户效果评分：内容基础为原 R1 阅读价值+当前价值+显式兴趣/反馈及已有同作者负反馈上限；话题只有自身兴趣匹配。有效重要性加 2，公共关注加 1。推荐复用 R1 的窗口 10、同源 3/0.75、同主领域 4/0.5 软多样性；话题按成员真实来源集合参与，同源只计一次。并列按有效时间降序、类型/ID。分量、缺失信号、召回和惩罚可查。

最新按时间，不按偏好。内容 original 优先，editorial/question_created 有据日期沿用既有口径；feed/reprint/modified/处理时间不替代。话题按合格实质进展 occurred 优先、reported 后备，取最大有据时间；未知排后。日期仅用上海日界内部比较，响应不伪造时刻。导读/转载/观测更新不置顶。

两种排序保留全部候选 ID。同页出现合格话题时，仅明确 reprint 或经审核 duplicate 的成员概况压为 reference，保留题名、原文/详情 ID、版本及关联话题；opinion/explanation/experience 保护，普通 report/background 不推定重复。跨页或话题失效后完整展示。不会永久隐藏全部成员；页长绑定游标。

## 分页和验证
