# R2-10 混合阅读页面与隔离体验

## 页面和接口

- `/discover` 默认推荐，可切最新，使用 R2-08 混合响应，不在浏览器重新排序。保留 reference 卡片及独立详情入口。快照 409/过期 400 明示并重载第一页，不能拼接两份快照。分页及返回位置按排序/读者版本保存。
- `/topics/:id` 使用新增只读 `GET /api/topics/{UUID}`。按 ID 调用原 R2-07 公开资格，不查混合流分页或受召回/时效窗口限制。无资格为 404，不退回旧文本。返回概况、导读、实质进展、背景/观点及当前合格相关内容；逐条保留出处、引文、归属、限定和发生/报道时间及精度。
- 关注/反馈复用 R2-09 稳定目标、共享 Reader CAS、审计和幂等。旧兴趣/内容写入仍共享版本；409 展示服务器当前状态后等待用户重新操作，不自动重放旧意图。最新不因偏好在客户端重排。
- 新导航包含发现、我的关注及历史阅读入口；`/reading/:id`、旧事件流 `/`（另提供 `/events`）和 `/digest` 保持。生产首页仍为旧事件流；仅隔离预览以发现为首页。R3 精选不在本批。
- 沿用 reading.css 的视觉语言，覆盖明暗主题、窄屏、键盘、加载、空态、登录和网络错误；失败时不把缓存旧内容当作当前公开版本。

## 预览隔离

使用新的本地命名库 `unspun_r210_preview_*`，只复制已有已暴露材料，原 ID/材料/审核版本和时间保持。独立 evaluation ASGI 入口可展示明确标记的保留工程话题，正式 API 的 `qualified_topic_text` 不放宽，mock 仍不可公开。工程示例不计真实生成/审核或自动归并质量。预览通过真实数据库、HTTP API、Reader 事务及排序/分页运行，无前端拦截数据。

预览入口要求 loopback、显式本地身份、新隔离库和全部处理/发布开关关闭；禁止导读/后台付费入口，无 worker、无模型密钥、无预算分配。生产处理、发布、混合及偏好开关保持关闭；生产主入口切换留 R2-11。
