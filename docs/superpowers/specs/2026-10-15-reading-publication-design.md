# 中文阅读与发布契约重构

本轮用户授权系统性重构前台和实时事件流；实施优先级调整为发布可信度、恢复审核、阅读结构、视觉。保持现有 Postgres、worker、模型与排序公式，不引入新的服务。

## 诊断及证据

- `docs/evaluations/m3b/production-candidates.json` 的 2026-10-14 生产抽样 40 个事件中，5 个标题无中文，13 个标题与摘要完全相同。抽样不含文章审核载荷，不能据此断定每例均由预算触发，也不能推断当前生产占比。
- 本地开发库只读核对：1132 篇文章，0 个事件；不用本地库冒充生产。
- `summarize_article` 的预算回退把原始标题写入两个中文字段；空事实和标题审核失败也回退原文。`pending_summary_conditions` 只找空摘要，因此预算恢复不会重新审核。语言来自 source.lang，不验证输出。
- `assign_article` 用首篇摘要建立事件，后续只改质心与 changed_at。`feed_page` 无发布门槛，评分也不能替代质量审核。
- 未完成审核指摘要事实的语义审核延期，不是来源信誉评级。现有 limited 表示材料有限，亦非审核失败。

## 各阶段职责

| 阶段 | 准入与产出 | 失败、恢复与观测 |
| --- | --- | --- |
| 采集 | 保留地址、原文、标题、来源与原始报道时间；source.lang 仅提示 | 原文失败保留 feed_summary / unknown，不伪造正文 |
| 清洗去重 | 同批 URL 去重；规范文本指纹复用完全相同的审核结果，保留每篇出处 | 不把不同域名算独立证据，不做未经验证的语义合并 |
| 收录 | 留存不等于发布；来源可信度只作来源属性 | 线索、待审核、失败均可在后台追溯 |
| 聚合 | 沿用摘要后 embedding；同事件从合格文章选代表内容 | 首篇失败不污染后续；新转载不成为事实进展 |
| 生成 | 原文引文绑定中文事实、独立记录标题审核结果 | 保存待审核草稿；原文标题只存在原始材料字段 |
| 审核 | 语义审核 + 引文匹配 + 中文可读性 + 去重 + 信息增量 | 预算延期可恢复；语言失败有限重试；无事实终止为线索 |
| 评分精选 | 质量准入先于公共阅读；保留重要性、来源质量和活动三种不同含义 | 分数不能使不合格内容发布；不把评分理由当事实性影响结论 |
| 发布更新 | 数据库分页前筛合格事件；事实携带 article_id/quote；日报新快照同门槛 | 质量变化使游标失效；历史日报保留原快照；不宣称已具备实质进展检测 |

## 内容形态与默认门槛

- 消息线索：只有标题、无新增事实、中文不完整或审核未完成；留后台，不进入默认阅读流。
- 快讯：已审核中文标题及至少一条超出标题的信息，有对应原文；明确标为快讯，不扩写凑长度。
- 报道摘要：至少两条去重事实且具备一定细节（首版 60 个中文字符），仍称摘要，不假装全文。长度仅是形态判断，不是正确性证明。
- 事件聚合：至少两篇合格材料实际贡献不同事实，说明是多篇综合；不能把报道数量当作独立验证。

中文检查是保守的字符/词比例检查，容许专名与缩写；不能代替自然度人工验收。语义近重复与事实进展需要后续评测，不靠新时间戳、来源数或相似字符串臆造。

## 实施顺序

1. 统一发布契约：复用 summary_grounding JSON 保存有版本、输入指纹和原因的 reading 投影，不新建任务系统。旧载荷缺少标题审核凭证时保持待处理，通过既有 worker 有界恢复，不把历史状态改写成已审核。
2. 修复预算延期和语言异常恢复；完全相同材料复用审核，保留出处。发布前分页过滤、同门槛生成日报；后台显示发布原因与审核积压。
3. 阅读工作区：共享后台蓝灰 tokens、224px 导航、8px 面板。正文宽度控制，列表以分隔线组织。默认只看事件标题、去重事实和紧凑来源入口；展开看到逐条证据、材料状态、评分与观点。不展示系统处理/生成时间。
4. 隔离数据库测试、现有标准集回归、真实历史抽样审计与明确标记的模拟预览、桌面/窄屏/暗色检查。自动化不代替用户体验验收；按 D-012 在本地验收后提 PR。

## 待验证

生产只读快照已补齐，详见 `docs/evaluations/reading/production-audit.json`：8843 篇文章、6193 个事件、4208 篇审核预算延期且全部已聚类；最近24h审核成本约 $0.4026。60 字形态阈值与中文比例需要真实样本持续校准。历史快照缺审核凭证的内容不能伪装已发布；上线后需观察 worker 在既有预算内的恢复速度。此次不提高预算、不自动全量重评分、不改历史日报。

## 实施审查补充

聚类只是候选关系，不自动授权拼接正文。跨文章合并要求与代表材料共享足够长的原始/已审核标题，或共享具体已审核事实；无共同依据的成员仍保留在来源区，并注明未纳入当前摘要。这是保守的确定性门槛，不能替代后续事件级语义审核或人工聚类纠正。事实去重保留小数点、负号等有意义的数字符号。延期审核可恢复，队列仍以新报道优先，避免历史积压抢占全部预算；相同报道时间下优先恢复延期项。若新增量持续超过审核容量，历史积压不能保证清空，后台应如实显示。原文改变重新进入待处理；新日报导语也检查中文，失败不覆盖快照。

## 历史兼容的证据边界

通过原 v5 代码可以确认：语义审核路径中的 `title_zh` 只会取审核通过的标题，或精确回退到原始标题。因此，仅对 v5、已完成语义审核、且译标题不同于原始标题的记录，免费恢复标题审核凭证，并重新跑当前中文、引文与信息量检查。记录 `title_verification_basis=v5_supported_translation_branch`，不伪造新的模型调用。原文与译标题相同、审核延期、版本未知的记录继续等待实际审核；40例导出的历史快照未含这些载荷，仍不能恢复凭证。每轮最多恢复500篇，不扩大模型预算。
