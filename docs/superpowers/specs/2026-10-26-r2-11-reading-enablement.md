## 有限范围与开关

- 正式 `unspun.api.app:app`、原 Access JWT 认证、内容资格和来源/材料门槛保持。只启用混合读取和发现首页，既有合格内容按原当前时效窗口进入候选，不新增抓取、补生成或导入工程话题。
- 新增 `UNSPUN_R2_DISCOVER_HOME_ENABLED`，应用默认 false；正式能力仅在它与 `UNSPUN_R2_HYBRID_ENABLED` 同为 true 时返回 `home: discover`，否则 `home: events`。`engineering_preview` 固定 false。
- PR 中生产 Compose 为上述两项提供可覆盖的 true 默认值；合并后的生产部署会启用，因此 PR 必须等待授权。部署变量 `R2_HYBRID_ENABLED` / `R2_DISCOVER_HOME_ENABLED` 可各自设 false 回退；基础/本地配置默认 false。
- 成员处理、话题合成、话题发布、话题偏好在 API/worker 继续显式 false。不添加任何付费阶段分配，legacy worker 始终 0，既有受控 R1 worker 范围不变。
- 原 `/events`、`/digest`、`/reading`、`/reading/:id`、旧事件/日报链接及 PWA `/digest` 保留；仅 `/` 的正式能力配置切到已有 `/discover`。关闭首页开关可恢复 `/`，不删数据、不回退 schema。

1. 新库迁移至 `000021`，完成基线回归；只读核对生产镜像/健康版本、schema、开关、合格详情、读者、预算、未知预留及保留文件。生产和原评测使用 `REPEATABLE READ` + `READ ONLY`；不查询提供方、不初始化/结算预算。缺失的当前提供方证据、主观评价、真实话题质量均保留缺失。
