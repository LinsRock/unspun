# M1 任务板 · MVP：验证聚类与评分

使用方式：

- 本任务板由 AI 维护。里程碑开工时拆解任务、经用户确认；每个任务对应一个 PR，完成后在该 PR 里勾掉。
- 需求以 `docs/requirement.md` 和 `docs/roadmaps.md` 为准——两者仍在演进，需求变了先改文档，再回来同步本任务板。
- 任务条目写成自包含（目标 / 涉及范围 / 验收 / 依赖），新会话不需要历史对话即可执行。
- 标注【人工】的任务由用户完成，AI 不代办。
