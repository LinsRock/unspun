# M2 任务板 · 观点对比与日报

使用方式：

- 本任务板由 AI 维护。里程碑开工时拆解任务、经用户确认；每个任务对应一个 PR，完成后在该 PR 里勾掉。
- 需求以 `docs/requirement.md` 和 `docs/roadmaps.md` 为准——两者仍在演进，需求变了先改文档，再回来同步本任务板。
- 任务条目写成自包含（目标 / 涉及范围 / 验收 / 依赖），新会话不需要历史对话即可执行。
- 标注【人工】的任务由用户完成，AI 不代办。

里程碑范围（见 `docs/roadmaps.md` M2）：自建 RSSHub、扩源到 ~100、观点对比、每日日报、响应式 + PWA。

开工时已确认的口径（用户，2026-10-09）：

- 观点对比先用 `google/gemini-2.5-flash`，输入用摘要而非全文（见 D-011）；试运行抽查质量不足再升级。
- 日报生成时间：北京时间 08:00（可配置）。
- 管理后台排期定为 M3，不进 M2。
- 扩源"宁缺毋滥、允许不满百"：路由验证不通过的源记录原因后放弃或换替代源，最终数量落在 80–100 之间即可。

## 开发任务

- [ ] T1 RSSHub 容器接入 — 目标：自建 RSSHub 跑起来，供后续中文源使用。范围：`deploy/compose.yml`（+ local/prod overlay）新增 `rsshub` 服务（官方镜像 `diygod/rsshub`，固定 tag），只挂内部网络、不发布任何端口，开内存缓存；`server/src/unspun/core/config.py` 新增 `UNSPUN_RSSHUB_URL`（默认 `http://rsshub:1200`）；`deploy/deploy.sh` 无需改动（镜像随 compose pull）。验收：本地 `docker compose up` 后从 api/worker 容器内可访问 RSSHub 健康检查；生产部署成功且未新增公开端口（硬规则：仅 127.0.0.1:8080）。依赖：无。
- [ ] T2 RSSHub 源 URL 解析 + 6 个中文源接入 — 目标：补上 D-008 推迟的财新、澎湃、界面、联合早报、机器之心、36氪。范围：`config/sources.yml` 支持 `rsshub://<route>` 形式的 URL，`unspun.core.sources` 加载时用 `UNSPUN_RSSHUB_URL` 解析成完整地址（本地开发可指向 localhost 映射）；逐个验证路由在 VPS（数据中心 IP）上实际可抓，付费墙/反爬导致拿不到的源在本任务板"扩源验证记录"登记原因并放弃或换替代源；每源带 weight/region/kind/lang 标签。验收：接入的源在生产连续两轮抓取成功并出现在文章库；放弃的源有记录。依赖：T1。
- [ ] T3a 扩源批次一：通讯社、综合与国际、经济、政治 — 目标：按 `docs/requirement.md` 初版清单补齐该领域组的中英文源。范围：`config/sources.yml` 新增源（Reuters、AP、AFP、新华社、NHK World、Nikkei Asia、端传媒、Bloomberg、WSJ、IMF/央行公告、Foreign Affairs、Foreign Policy、Politico、澎湃国际等，已在 M1 接入的跳过）；每源上线前逐个验证 RSS/RSSHub 路由可用并记录；付费墙源只有标题导语属预期（贡献广度信号）。验收：新源全部在生产抓取成功 ≥2 轮，失败源出现在运行报告并处理；验证记录更新到本文件。依赖：T1（涉及 RSSHub 路由的源）。
- [ ] T3b 扩源批次二：科技 AI、学术、医学、气候、太空 — 范围：arXiv（cs.AI/CL/LG）、Ars Technica、The Verge、MIT Tech Review、AI 实验室官方博客、Simon Willison、Stratechery、量子位、少数派、STAT News、Nature/Science 新闻、NEJM、Lancet、丁香园、Carbon Brief、Inside Climate News、IEA、SpaceNews、NASA、ESA 等。验收与做法同 T3a。依赖：T1。注意：arXiv 量大，设 `max_items`。
- [ ] T3c 扩源批次三：人文社科、破圈区、长文精选、社区平台 — 范围：Aeon、Psyche、澎湃思想市场、The Atlantic、The New Yorker、Pew Research、三联、NYT Books、LRB、Guardian Culture、豆瓣书评影评、Quanta、Lawfare、Dezeen、War on the Rocks、The Athletic、The Browser、Longreads，以及社区平台 HN、精选 Reddit 版块、微博热搜、知乎热榜（weight 0.3）。设计口径：社区源文章照常入库、聚类，作为广度信号与链接；客观分的 community 子分仍恒 0，接入与领域归一化一起放 M3 评估。验收与做法同 T3a。依赖：T1。
- [ ] T4 数据模型迁移：观点对比与日报表 — 目标：为 T5/T7 建表。范围：Alembic 迁移新增 `event_viewpoints`（event_id 唯一外键、payload JSON、input_fingerprint、model、generated_at，重新生成时整行替换）和 `digests`（report_date 唯一、kind='daily'、payload JSON、generated_at）；`unspun.core.models` 同步。无删表删列。验收：迁移在 CI 与本地跑通，pyright/pytest 绿。依赖：无。
- [ ] T5 观点对比管线 — 目标：对来源足够多样的事件生成观点对比，每条说法可溯源。范围：`unspun.pipeline` 新增 viewpoints 阶段：资格门槛（≥3 个独立来源且跨 ≥2 个地区或 ≥2 种类型，常数进 `config/scoring.yml` `viewpoints` 段，含 `viewpoint_batch_limit`）；输入为各来源中文摘要 + 标题 + 导语（见 D-011）；输出固定 JSON——各来源说法列表（每条带 article_id 与一句话立场/主张）+ 分歧点列表（引用说法条目）；input_fingerprint 取事件文章 id 排序后哈希，指纹不变不重生成；模型默认 `google/gemini-2.5-flash`（`UNSPUN_VIEWPOINT_MODEL` 可覆盖），按 D-007 记账；fake LLM 单测覆盖门槛、指纹、JSON 解析失败路径。验收：生产跑一轮后，多样性达标的事件有观点对比且每条说法的 article_id 均属于该事件；不达标事件不调用 LLM；日花费可在运行报告看到增量。依赖：T4（T2/T3 扩源后多样性事件更多，但不阻塞）。
- [ ] T6 观点对比前端展示 — 目标：宽屏并排读观点对比。范围：`/api/events` 返回体挂 viewpoints；`web/src` 事件卡片展开或详情区渲染：各来源说法分栏并排（窄屏纵向堆叠），每条说法链接到原文（复用 safeHref 规则，D-009）；分歧点单独一节；Vitest 断言说法与链接对应关系。验收：抽查若干事件，说法与来源链接一一对应、无张冠李戴（M2 验收标准）。依赖：T5。
- [ ] T7 日报生成管线 + API — 目标：每天北京时间 08:00 生成日报。范围：worker 循环检测跨过生成时刻（时区与时刻进 config：`digest_hour: 8`、`digest_timezone: Asia/Shanghai`，放 `config/scoring.yml` digest 段或 core 配置）后生成当日日报：取过去 24h 按衰减分排序的 top N 事件（N 进 config），组装已有摘要、分数、观点对比引用，LLM（flash-lite 档）只写一段当日导语；写入 `digests` 表，同日重跑幂等（替换）。API：`GET /api/digest/latest`、`GET /api/digest/{date}`（注意与现有运行报告 `/api/report/daily` 是两回事，命名用 digest 区分）。单测覆盖选取窗口、幂等、时区边界。验收：连续数日 08:00 ±一个轮距内生成（7 天记录在 T10 完成）；API 可取任意历史日报。依赖：T4。
- [ ] T8 前端路由改造 + 日报页面 — 目标：三页结构，手机上能顺畅读日报。范围：引入 react-router-dom；页面：`/` 实时事件流、`/digest`（默认当天，可切换历史日期）、`/report` 运行报告面板；响应式导航栏；日报页渲染导语 + 事件列表（含原文链接与观点对比摘录）；Vitest 覆盖路由与日报渲染。验收：手机宽度下三页可用，日报页可读历史日报。依赖：T7。
- [ ] T9 PWA 与离线日报 — 目标：可安装到手机桌面，断网可读当天日报。范围：vite-plugin-pwa（Workbox）：manifest（名称、图标）、app shell 预缓存；TanStack Query 缓存持久化到 IndexedDB（persister），日报查询离线可回放；`deploy/Caddyfile` 确认 sw.js 与 manifest 正确供给。验收（M2 验收标准）：手机安装到桌面后开飞行模式，能打开当天日报。依赖：T8。注意：Cloudflare Access 的会话 cookie 不影响离线读缓存，但首次安装需在线登录。
- [ ] T10 里程碑收尾 — 目标：对账与验收记录。范围：观点对比抽查（每条说法附来源链接、无张冠李戴）、日报连续 7 天按时生成记录、断网读日报实测，结果记入本文件"验收记录"；`docs/requirement.md`、`docs/roadmaps.md` 与实现对账；经用户确认后开 `docs/tasks/m3.md`。依赖：全部。
