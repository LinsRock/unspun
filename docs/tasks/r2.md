### R2-05 · 话题、成员与版本底座

- [ ] 增量增加事件/议题话题、内容多对多关系、关系依据/变更历史及进展和派生版本的最小结构。
- [ ] 固定规范内容身份、关系类型、版本/指纹、证据与时间含义；主题词和话题资源分别表达。

出口：同一材料可涉及多个话题，独立内容无需归并也能继续推荐；有可核对的成员/版本及迁移恢复证据。

### R2-06 · 候选召回、成员判断与最小纠错

- [ ] 按需 embedding，并用领域/主体/时间召回少量候选；同一事件或议题须另有语义判断，不确定先独立。
- [ ] 将判断任务、向量及审核接入原队列和共享预算，扩展所需类型/上下文并明确阶段分配；重试保留物理费用。
- [ ] 固定技术样本和留出，检查同主体不同事件、跨源转载、独立观点、部分重叠、长时间背景及多话题。
- [ ] 后台补成员/依据、任务与费用下钻和可审计的最小纠错；修正成员后使受影响派生失效。

出口：归并精度与覆盖在真实固定样本上分别报告；同企业不同事件不混聚，低置信内容不因聚类失败失去独立入口。

### R2-07 · 实质进展、话题概况与导读

- [ ] 区分重复、背景、观点和实质变化，涵盖有依据的新讨论焦点；每项进展保存材料依据、归属、时间含义/精度及修订历史。
- [ ] 用成员材料版本集合生成有依据的中文概况/导读，主张逐项保留归属、限定与引用；部分材料不扩写成完整讨论。
- [ ] 验证转载/新增来源不刷新进展，材料更正或来源关闭后旧话题文本不能绕过发布门槛。
- [ ] 验证任务去重、领取过期/晚返回、预算延期及失败恢复；话题未就绪时合格独立卡片仍可用。

出口：真正进展可追到材料，合格生成与已发生费用均可复核；没有进展或没有足够材料时如实不生成。

### R2-08 · 混合候选、排序与稳定分页

- [ ] 重要动态、兴趣和真实公共关注候选分别召回再融合，缺失热度信号不伪造；权重/时间范围先登记再同样本比较。
- [ ] 话题与独立内容在同一响应中有明确类型与版本，版面抑重保留独特解释/观点，不把成员全部永久隐藏。
- [ ] 内容最新按原发，话题最新按有依据的实质进展；处理/导读/转载不置顶，未知时间明确标注。
- [ ] 验证稳定快照、翻页、返回、候选变化/偏好更正后的冲突以及同域/同源多样性；不使用隐式已读。

出口：同批真实样本能核对推荐、最新及推荐理由，减少重复概况并保留独立阅读价值；性能与费用适合既有部署资源。

## 4. 检查与执行约束

文档改动检查本地链接、状态一致性、差异格式与 CI 范围；不为说明性文档重复运行无关应用测试。采样/查询改动运行定向及相关完整回归，数据库测试明确指向新建迁移隔离库。生成、归并和排序变更增加固定真实样本与旧边界回归；页面保留真实 API 体验证据。

预算沿用项目 $15/月、生产 $13.50、原累计评测 $1.50、生产审核 $0.40/24h 及原模型；后续付费前刷新当前读数并登记小范围成本，既有分配不是新余额。所有调用共享总额，原未知预留不释放、不补零，不另建平行额度。来源、话题和阶段关闭都不得恢复 legacy worker。
