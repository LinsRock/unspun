1. 总览查看产出趋势、健康分布和积压；点击待摘要进入队列。

3. 内容页勾选记录，导出选中项；切换分页或筛选后选中状态不跨范围残留。
4. 通过 ⌘/Ctrl K 搜索内容或切换工作区；检查日期范围跨页面保留。
5. 费用页切换统计口径，查看预算、明细、账目和续费；配置页不展示日期筛选。
6. 切换暗色与 390px 手机尺寸，检查导航、局部表格滚动与详情。
