# 新生计划：第一轮真实材料试读

用户于 2026-11-04 同意开展真实材料、可点击原型和有界复用验证。设计依据见[最小架构与 AIHOT 对照](../../superpowers/specs/2026-11-04-rebirth-architecture-comparison.md)。本目录是独立试验，不接入现有运行系统；正式仓库、技术栈及下一批自动处理尚未确定。

本批交付：24 份真实材料，覆盖航天、交通、AI、知识、生活、文化与环境等选材范围；精选、热点阅读样张及共享详情；AIHOT 实际组件提取和关键差异结论。先检查阅读与业务对象，再决定正式实现。本轮不运行旧 R2 评测、生产采集、付费模型或数据迁移。

## 运行

```sh
node docs/design/rebirth-reading/server.mjs
```

打开终端输出的本机地址。Node 内置 HTTP 服务只监听 `127.0.0.1`，不需要依赖安装、数据库、密钥或外部请求。通过 `--port 4318` 指定端口；`--state-dir /absolute/path` 指定试读反馈目录。默认状态在系统临时目录下独立保存，不修改样本；停止后可用同一命令再次启动。

## 阅读证据

`data/` 保留原文链接、来源、原发日期、实际可读范围和核对说明。卡片与详情是本轮根据实际材料整理的试读文案，**不是自动流水线生成质量的证据**。历史材料不表示当前新闻或热点。热点页仅展示事件阅读结构；没有真实关注观测时不显示热度、名次或趋势，也不据此宣称热点发现已验证。

试读反馈用于收集“值得读／没读懂”的判断，保存在本机服务；不自动隐藏内容或改变排序，不作为正式兴趣学习实现。浏览本身不写反馈。

## 验证范围

```sh
node --test docs/design/rebirth-reading/tests/*.test.mjs
```

检查样本引用与日期、按类型分页及重复项、无事件归属文章独立读取、热点缺观测状态、反馈保存与撤销、只读访问和未知路由。电脑与窄屏浏览器另检查真实 API 下的筛选、详情、返回和键盘操作。组件提取的执行方法及结论见 [REUSE.md](REUSE.md)。

## 本批结果

- 24 份材料中，18 份核读公开正文、4 份仅取得部分材料、2 份原页不可用而仅保留线索。正文范围不代表存储了原文全文；只保存简短整理和出处。
- 精选共 16 项：3 个事件、13 篇独立文章。视频入口隐藏。首屏交错呈现事件和无事件归属的文章，事件相关分析保留独立阅读资格；这是固定样张编排，不是推荐算法效果。
- 9 项原型检查通过，覆盖真实 HTTP、分页、反馈重启保存/撤销以及迟到请求不覆盖新页；AIHOT 提取与发布策略试验在 UTC、上海时区各 30 项通过。CI 路由 12 项通过。
- 已在本机 Chrome 确认桌面列表与文章详情实际渲染。内嵌浏览器连接不可用，独立 Safari 访问未获自动审批；窄屏视觉与完整浏览器交互检查尚未完成，未据此登记手机体验通过。
- 推荐采用独立业务实现与选择性复用进入下一批设计，理由及尚未证明的部分见 [REUSE.md](REUSE.md)。本批用户阅读验收仍待反馈；热点时效、自然新增及自动整理质量保持未测。
