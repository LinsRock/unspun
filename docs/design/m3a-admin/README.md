# M3-A 后台查询版原型

范围：六页布局、日期范围、统计下钻、费用口径、源排序、内容/运行详情和模拟账目录入。原型固定在 2026-10-12 14:00，北京时间；所有数据为设计示例，不查询生产，不代表实际源数、新闻或费用。

## 启动

在本工作区根目录执行：

```bash
python3 -m http.server 4186 --bind 127.0.0.1 --directory docs/design/m3a-admin
```

打开 `http://127.0.0.1:4186`。局域网手机需自行使用可达的本地服务地址；本原型不自动发布到公网。

## 体验

1. 点击顶部时间按钮，在快捷范围中选“昨天／本月”，或用双月历选择自定义范围；取消不影响当前查询，应用才生效。手机为单月日历。
2. 总览只保留三项关键指标、一张可切换趋势图和当前状态；整块信息源卡片可进入列表。图表具有零起点纵轴、单位、网格、悬停/键盘读数，点击进入时段明细后可返回总览，原全局范围保持不变。
3. 费用切“期间成本／实际支出”，按用途/模型查询；查看固定账目，模拟新增和确认付款。账目仅在本次页面会话保存，刷新恢复初始示例。
4. 信息源切“异常优先／文章产出／失败率”；点击来源详情，进入该源文章，再进入事件时间线。然后回总览点文章指标，应打开完整区间文章而不残留刚才的源筛选。
5. 文章切换“入库时间／报道时间”；事件按最早报道时间筛选，“今天”没有新事件但仍有新入库文章是正常示例。
6. 查看运行详情、配置与操作记录：历史缺失字段显示未记录，后续操作能力标注 M3-C。口径和长解释折叠到说明区域。
7. 用浏览器窄屏 400px 检查手机布局；桌面左下切深浅色。

## 限制与后续

- 原型只演示部分筛选控件；完整语言、地区、类型、处理状态等筛选按后台产品设计和交付拆分实施。
- 表格局部允许滚动，手机隐藏次要列并从详情读取，页面整体不横向溢出。
- 固定费用按与查询相交的北京时间自然日分摊，今日按一个覆盖日计；调用费用按明确时刻筛选。固定费用日粒度分摊不用于解释小时级成本。
- 兑换率为明确标注的演示值；正式版需要原币、有效汇率与缺失状态。示例费用采用 USD 汇总。
- 原型不执行周期后台任务、供应商支付、配置修改、重跑、聚类纠正或生产审计。演示账目确认不代表真实付款。
- 本原型体验与生产页面 D-012 验收分别进行。

实现拆分见 [M3-A 交付拆分](../../superpowers/plans/2026-10-12-m3a-admin-delivery.md)。

## 第二版参考与交互原则

- 日期选择参考 [Ant Design RangePicker](https://ant.design/components/date-picker/) 的快捷范围与区间选择；原型实际使用本地固定版本 [flatpickr 4.6.13](https://flatpickr.js.org/examples/)，MIT 许可证随 vendor 保留，不访问 CDN。正式 React 组件选型在 A1 设计中确认，不由静态原型决定生产依赖。
- 时间筛选与下钻参考 [Grafana 时间控制](https://grafana.com/docs/grafana/latest/visualizations/dashboards/use-dashboards/)。全局范围与局部时段分开；取消日期草稿不触发查询。图表下钻清除无关模型/来源筛选，页内筛选单独保存。
- 图表轴与单位参考 [Carbon 轴与标签](https://carbondesignsystem.com/data-visualization/axes-and-labels/)；柱形纵轴始终从零开始，费用与文章不共用单位。无数据展示空状态，不用极小假柱表示零。
- 总览目标是快速判断产出、成本与异常；运行明细与解释逐步展开。来源状态卡片、异常行整块可点击，而不是只允许点箭头。
