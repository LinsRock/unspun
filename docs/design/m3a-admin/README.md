# M3-A 后台查询版原型

范围：六页布局、日期范围、统计下钻、费用口径、源排序、内容/运行详情和模拟账目录入。原型固定在 2026-10-12 14:00，北京时间；所有数据为设计示例，不查询生产，不代表实际源数、新闻或费用。

## 启动

在本工作区根目录执行：

```bash
python3 -m http.server 4186 --bind 127.0.0.1 --directory docs/design/m3a-admin
```

打开 `http://127.0.0.1:4186`。局域网手机需自行使用可达的本地服务地址；本原型不自动发布到公网。

## 体验

1. 总览切“昨天／本月”，点击文章或费用卡片，确认区间跟随跳转；当前状态保持不变。
2. 费用切“期间成本／实际支出”，按用途/模型查询；查看固定账目，模拟新增和确认付款。账目仅在本次页面会话保存，刷新恢复初始示例。
3. 信息源切“异常优先／文章产出／失败率”；点击来源详情，进入该源文章，再进入事件时间线。
4. 文章切换“入库时间／报道时间”；事件按最早报道时间筛选，“今天”没有新事件但仍有新入库文章是正常示例。
5. 查看运行详情、配置与操作记录：历史缺失字段显示未记录，后续操作能力标注 M3-C。
6. 用浏览器窄屏 400px 检查手机布局；桌面左下切深浅色。

## 限制与后续

- 原型只演示部分筛选控件；完整语言、地区、类型、处理状态等筛选按后台产品设计和交付拆分实施。
- 表格局部允许滚动，手机隐藏次要列并从详情读取，页面整体不横向溢出。
- 固定费用按与查询相交的北京时间自然日分摊，今日按一个覆盖日计；调用费用按明确时刻筛选。固定费用日粒度分摊不用于解释小时级成本。
- 兑换率为明确标注的演示值；正式版需要原币、有效汇率与缺失状态。示例费用采用 USD 汇总。
- 原型不执行周期后台任务、供应商支付、配置修改、重跑、聚类纠正或生产审计。演示账目确认不代表真实付款。
- 本原型体验与生产页面 D-012 验收分别进行。

实现拆分见 [M3-A 交付拆分](../../superpowers/plans/2026-10-12-m3a-admin-delivery.md)。
