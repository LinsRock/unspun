# R1 内容排序实施暂定值

记录于内容流实现前。沿用 `technical-suite-v1.json` 的阅读价值、当前价值、关注上限、正负反馈及软多样性边界；具体匹配权重与软惩罚补于 `config/r1-reader.yml`，属于 AI 实施暂定参数，不是用户评价或已确认产品阈值。

推荐分值为已审核阅读价值、按真实发布时间计算的当前价值、关注匹配（总计最多 2）、明确反馈之和。同一条负反馈只额外影响具有相同已核实平台作者 ID 的内容，最多 0.25；不扩展为领域排除。逐项给出实际匹配和分值。软多样性在全体候选上稳定计算，然后分页；最近 10 个位置同来源超过 3 或主领域超过 4 时分别扣 0.75/0.5，不强行填充低质量材料。最新按原始/编辑版/问题创建的支持时间排序，不按抓取、导读生成或榜单时间刷新。

关注来源只匹配实际来源身份；作者只按平台和已取得的作者 ID 或明确署名匹配，不声称新增作者采集。只有已审核、当前材料一致、来源获准发布的独立内容进入正式流。隔离技术预览必须同时满足本机请求、本机认证预览开关、专用评测库和评测预算策略；生产不能使用此旁路。

游标固定排序时点、内容版本和偏好版本，15 分钟到期；材料修订、审核状态、来源发布范围或偏好变化返回冲突，要求重新加载。GET 不生成导读、不记阅读隐藏、不触发付费。日期精度不会补成对外声称的午夜时间。R0 人工卡片和本地材料缓存不是正式 API 数据。
