# R2-01 冻结基线

范围与真实读数见[取证报告](../../acceptance/r2-01-supply-baseline-2026-10-19.md)。本目录保留 R2-01 的变更前材料与比较口径；R2-02 的新对照单独登记为 v2，R2-03 检索/详情另建 v3；R2-04 新来源对照另建 v4，两路观察中且继续关闭；R2-05 底座及 R2-06 第一批关闭工程链已交付；第二批真实评测见下，整体未完成。

- [选择登记](selection-v1.json)：30 条近期发现的真实候选，20 回归、10 留出，相关材料家族同组；抽样有目的，不当作入选率分母。
- [输入](inputs-v1.json)：已存材料、元数据、出处、原始时间依据及指纹，不再依赖在线取材。
- [技术期望](technical-expectations-v1.json)、[关系样本](relations-v1.json)：AI 技术审阅身份；材料支持、时间、归属、部分正文、相同主体不同事件及多话题边界。缺失真实样本单列，不代表归并算法已通过。
- [变更前结果](before-change-v1.json)：固定 `as_of` 的现有推荐/最新序列、30 个输入契约/处理指纹重放；不新增模型调用。
- [用户评价](user-review-v1.json)：值得看、兴趣及遗漏参考单独为空，不以 AI 期望或原重要性分代填。
- [冻结清单](freeze-v1.json)：这些文件、只读截面、配置、旧 R1 回归和原用户标注的字节哈希；后续新增版本保留本版。

后续比较使用清单中的相同输入、来源、材料、时间、偏好和原模型，分开报告发现/材料/技术失败/准入/排序。留出未参与调试；登记审阅不冒充盲采，不能反复用留出调参。已验证转载链、可信旧原发知识材料及发生时间不足继续列为缺口。

本地执行 Python 前须显式设置当前 worktree 的 `PYTHONPATH="$PWD/server/src"`；共享环境原 editable 指向旧 worktree，不可直接信任。数据库测试只使用新建迁移隔离库，生产与原累计评测库仅只读；检查清单哈希和已冻结输入不需要数据库或提供方网络请求。

R2-02 的 [扫描对照 v2](scan-comparison-v2.json)分别记录六类适配器的同响应工程比较、实际配额变化、30 份冻结输入的契约/处理指纹重放与费用场景；合成列表不是 R2-01 失去的真实扫描历史，也不补关系质量或用户评分。`freeze-v1.json` 本身及历史哈希保持；其中 `config/sources.yml` 是基线 revision 的 blob，配置变更后用该 revision 核验，不能将新的运行配置强行改回旧哈希。其他冻结目标仍可按当前文件直接核验。

R2-03 的[候选对照 v3](candidate-comparison-v3.json)在新建迁移隔离库重放相同 30 份当前材料和原来源/卡片，验证处理指纹、公开集合、推荐/最新顺序及分值不变。两侧显式采用相同空兴趣/反馈，未完整取得旧偏好记录，因此不冒充原生产全体排序的复现；留出仅作契约和未改规则核验，没有调参。>1,000 条压力、查询计划和自然轮次补证见[验收报告](../../acceptance/r2-03-candidate-detail-2026-10-20.md)；合成压力不是新增真实质量、来源召回或用户评价。v1、scan v2 及全部历史评分保持。


R2-04 的[来源比较 v4](source-comparison-v4.json)保存四路当前目标响应、真实材料与转载贡献、两路选择及首次失败；[费用投影 v4](source-cost-projection-v4.json)同时覆盖原八路、新两路、审核/重试/导读及未知压力。新观察先[登记](source-increments-window-v1.json)，不复用旧探针充窗口；关键字段/跨日、付费生成和预算启用门槛未齐，路径保持关闭，详见[阶段报告与恢复入口](../../acceptance/r2-04-source-increments-2026-10-20.md)。此 v4 不覆盖 v1/v2/v3，不增加用户评分、留出调参或归并质量结论。


R2-06 第二批的[原材料包及追加锚点](member-inputs-v1.json)、[样本/锚点/指标/门槛/费用/请求登记](member-registration-v1.json)和[独立冻结清单](member-freeze-v1.json)在付费前固定，沿用原 30 条及原 20/10 分组；付费子集为 6 回归/5 留出，原 20 条合格、10 条排除另列。追加两条真实材料按关系家族归组；缺失的真实转载、旧原发背景及发生时间不由合成回归或长输入替代。原 v1/v2/v3/v4、全部用户空字段及原七笔预留保持。完整处理链和批次费用始终共用原累计评测库；新建隔离回归/恢复库不用于付费。执行与结果见[第二批验收](../../acceptance/r2-06-evaluation-2026-10-20.md)。

原累计库的首次正式追加遇到同 URL 不同材料的旧对象（8877 → 原对象 19），全事务回滚。付费前另冻[可用性修订](member-availability-v1.json)及[清单](member-availability-freeze-v1.json)：8877 保留不可用，已冻结真实评论 8903 增加回归查询角色；有效 11 查询（7 回归/4 留出），共登记 12、不可用 1，预期关联 6。初次 30 条/20-10 分组及全部原冻结不覆盖，也不将旧对象的不同材料代替本次输入。
