# Unspun 新版开发路线图草案

更新日期：2026-10-15。当前处于产品重定义与方案讨论阶段。用户已确认第一阶段的核心范围；下列交付批次是建议，不表示已经启动或完成应用实现。

需求见[新版需求](requirement.md)，实现建议见[重构方案](implementation-proposal.md)。旧版 M0–M6 路线保存在[历史路线图](roadmaps-legacy-2026-10-15.md)，历史任务、PR 与验收证据继续保留。

## 第一阶段目标

让用户每天打开 Unspun，能从当天精选和持续更新的信息流中，发现重要动态、感兴趣的话题及值得读看的内容；点击后通过 AI 导读、全文或原内容继续阅读，并通过关注和显式反馈改善选材。

国内平台和中文信息源优先，内容可涉及全球；作者和来源偏好作为补充。混合流默认推荐并可切换最新，精选随重要新增适度更新。兴趣、文章与视频均在本阶段内，手动收集和影响预测留待后续。

## 建议交付顺序

R0–R3 是本次重构的交付批次，用来区别历史 M1/M2/M3。按每批出口推进，不继承旧版 M3-A–G 的执行顺序。

| 批次 | 交付内容 | 出口 |
| --- | --- | --- |
| R0 定义与真实来源验证 | 产品定义、需求、实现方案；来源覆盖表、真实样本与评测基线 | 知道要收什么、能收什么、缺什么，以及如何判断选得对 |
| R1 自动发现到独立阅读 | 内容底座、来源任务、基本兴趣与反馈、独立内容流、卡片和内容详情 | 真实来源自动产出文章或视频等内容，无需先建事件即可推荐和深入阅读 |
| R2 话题与混合推荐 | 话题归并、实质进展、话题详情、混合信息流与个性化细化 | 热议话题和独立内容共存，能跟进变化，也能保留独有阅读价值 |
| R3 当天精选与第一阶段验收 | 当天选编、完整首页、来源覆盖补齐、成本与恢复、持续使用验收 | 当天精选和持续信息流共同提供稳定、值得看的阅读体验 |

各批按可独立评审的 PR 拆分，功能页接真实 API 后提供本地预览。最终页面需用户体验验收后才提页面 PR，自动测试不替代该流程。具体任务清单在每批实施前按本方案细化。

## R0 定义与真实来源验证

本轮已形成[产品定义](product-definition.md)、[需求](requirement.md)、[实现方案](implementation-proposal.md)和[有限来源初查](research/2026-10-15-source-feasibility.md)。其余采集验证、样本、阈值与原型均未完成。

下一步完成以下准备：

- 以[用户指定来源](source-plan.md)为优先范围，按重要领域、公共讨论、好文章和视频建立覆盖表，国内或中文来源为主；国际主干为 BBC、纽约时报和华尔街日报。
- 对候选路径获取真实条目，核实作者、原始时间、正文或摘要范围、互动观测、视频材料及运行依赖。
- 在目标部署环境跨时段验证，而非仅验证本地请求或路由存在；明确尚无法覆盖的内容。
- 固定包含入选与排除候选的真实样本，保留旧人工标注，补充独立文章、视频、讨论、小众好内容与时效边界。
- 用真实样本展示首页和两类详情，检验推荐默认与最新切换、精选随重要新增更新的体验，固定更新阈值或间隔及阅读密度等参数。

本批不以源总数作为验收。样本必须能支持目标体验的判断；如果视频或社区只有榜单标题，不能宣称已经验证内容级导读与全文能力。

## R1 自动发现到独立阅读

依赖：R0 对首批路径和样本的验证。

建议依次拆为数据与生成契约、来源任务、独立内容 API、兴趣与反馈、页面接入等 PR。兴趣从最小完整路径起参与选材，基础反馈同时可用。

- 扩展文章底表以支持文章、帖子与视频等内容，新增作者、类型、正文完整度及来源观测。
- 将元数据采集与正文获取拆成可恢复任务，提供轻量重复和明显过期筛查。
- 适配各类内容的简明整理、审核与基本导读，复用输入版本、调用记账和证据校验。
- 提供独立内容流、详情、领域或话题关注、作者与来源偏好、可撤销反馈；先用可解释匹配形成推荐。
- 以真实内容验证卡片、详情、原文入口、正文完整度及手机阅读；不要求先归入事件。

出口：同一条真实内容能从自动发现进入推荐、打开详情并反馈；重复提交不创建重复任务，已完成结果可复用，失败时已发生费用保留；反馈可观察地改变同批候选的排序。

## R2 话题与混合推荐

依赖：R1 的内容、偏好与任务基础。

- 新增话题与内容关系，召回后核实同一事件或议题；保留独立内容入口。
- 识别重复转载、背景、观点和实质变化，记录进展依据与时间。
- 提供话题导读与相关材料，话题和文章、帖子、视频共同进入信息流。
- 将重要领域候选、兴趣内容和公共关注信号结合，验证领域与形式多样性以及反馈效果。
- 固定推荐和最新的时间口径、稳定分页与返回状态；阅读不自动隐藏条目。

出口：相同企业的不同事件不会明显混聚，转载不冒充进展；同一版面既避免重复概况，也保留值得独立读的内容。话题详情、独立详情及推荐理由可从同一批样本核验。

## R3 当天精选与第一阶段验收

依赖：R2 的混合候选、话题与偏好能力。

- 对合格候选进行当天选编，保存选择理由与版本，首页提供当天精选和持续信息流。
- 依据 R0 定下的节奏更新精选，不让慢源或导读任务阻塞首页；记录更新时间与内容缺口。
- 按覆盖表补齐重要领域和主要内容形态，验证作者及来源关注的实际发现效果。
- 完成跨阶段预算、失败恢复、可观测状态与必要后台查询，保留旧快照及回退入口。
- 进行连续使用验收，分别检查覆盖、值得看比例、重复、误筛、时效、反馈、阅读和成本；窗口与阈值在 R0 固定。

出口：达到已固定的内容与运行验收标准，用户实际体验首页和详情通过；历史验收缺口仍如实保留，不因新版完成而改记旧版通过。

## 后续阶段候选

手动收集外部链接、微信公众号、小红书、更多全球来源、历史内容深入挖掘、搜索或稍后看、跨期报告及分发可按实际使用价值分别排期。

大事件 AI 影响分析或预测是后续候选：先明确分析对象、证据、假设、时间跨度和回看方式，再决定是否进入下一阶段。不因本轮提及就预先建设预测模块。

## 实施约束

继续复用现有工程、访问、模型档位和预算；数据增量迁移，不批量删除旧库或改写历史日报。评分与提示词调整通过固定样本评测；页面按本地体验流程交付。每批完成后对账实际状态，再推进下一批。
